php artisan serve => Development server চালাও

2. Artisan কী?
Artisan হলো Laravel-এর built-in CLI tool। এটি দিয়ে বিভিন্ন development task করা যায়

php artisan list => সব available commands দেখতে
php artisan --version => Laravel version দেখতে
php artisan route:list => Routes দেখতে
php artisan make:controller TaskController => Controller তৈরি করতে
php artisan make:model Task => Model তৈরি করতে

3. কিছু গুরুত্বপূর্ণ বিষয়:
- app/ — Application-এর মূল PHP code।
- routes/ — Application-এর routes।
- resources/views/ — Blade templates।
- database/ — Migrations, seeders ও factories।
- public/ — Public entry point ও assets।
- .env — Environment configuration।
- vendor/ — Composer-installed packages।
- artisan — Laravel CLI entry point।
